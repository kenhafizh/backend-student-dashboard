# Plan: Ubah Skema Create Attendance ke Array Format

## Tujuan

Mengubah endpoint POST `/attendance` dari format single record menjadi array format yang memungkinkan input multiple students dalam satu request dengan struktur:

```json
{
  "tanggal": "2026-05-23",
  "classId": "class-uuid",
  "absensi": [
    {
      "studentId": "student-uuid",
      "studentName": "Nama Siswa",
      "status": "HADIR"
    },
    {
      "studentId": "student-uuid",
      "studentName": "Nama Siswa",
      "status": "SAKIT"
    }
  ]
}
```

### 1. Update Service Layer (`src/features/attendance/service/attendanceService.ts`)

**Tambah interface baru:**

```typescript
interface AttendanceItem {
  studentId: string;
  studentName: string;
  status: Status;
}

interface CreateBulkAttendanceInput {
  tanggal: string | Date;
  classId: string;
  absensi: AttendanceItem[];
}
```

**Tambah function baru `createBulkAttendance`:**

```typescript
const createBulkAttendance = async (input: CreateBulkAttendanceInput) => {
  const { tanggal, classId, absensi } = input;

  // Validasi input
  if (!tanggal || !classId || !absensi || absensi.length === 0) {
    throw new Error("Field 'tanggal', 'classId', dan 'absensi' wajib diisi");
  }

  // Validasi status
  const validStatuses = ["HADIR", "SAKIT", "IZIN", "ALPHA"];
  for (const item of absensi) {
    if (!validStatuses.includes(item.status)) {
      throw new Error(`Status '${item.status}' tidak valid`);
    }
  }

  const attendanceDate = new Date(tanggal);
  attendanceDate.setHours(0, 0, 0, 0);

  // Validasi semua students ada di class yang diminta
  const studentIds = absensi.map((a) => a.studentId);
  const students = await studentRepository.findByIds(studentIds);

  for (const item of absensi) {
    const student = students.find((s) => s.id === item.studentId);
    if (!student) {
      throw new Error(`Siswa dengan ID '${item.studentId}' tidak ditemukan`);
    }
    if (student.classId !== classId) {
      throw new Error(`Siswa '${item.studentName}' tidak ada di kelas ini`);
    }
  }

  // Validasi tidak ada duplicate attendance untuk tanggal yang sama
  const existingAttendances =
    await attendanceRepository.findByStudentIdsAndDate(
      studentIds,
      attendanceDate,
    );

  if (existingAttendances.length > 0) {
    const duplicateNames = existingAttendances
      .map((a) => a.student.name)
      .join(", ");
    throw new Error(
      `Siswa ${duplicateNames} sudah tercatat absensi pada tanggal tersebut`,
    );
  }

  // Bulk create attendance
  const attendanceData = absensi.map((item) => ({
    studentId: item.studentId,
    status: item.status,
    date: attendanceDate,
  }));

  const createdAttendances =
    await attendanceRepository.createBulk(attendanceData);

  return createdAttendances.map((attendance) => ({
    id: attendance.id,
    studentId: attendance.studentId,
    studentName: attendance.student.name,
    status: attendance.status,
    date: attendance.date,
  }));
};
```

**Export function baru:**

```typescript

```

### 2. Update Repository Layer (`src/features/attendance/repository/attendanceRepository.ts`)

**Tambah methods baru:**

```typescript
const findByIds = async (ids: string[]) => {
  return prisma.student.findMany({
    where: { id: { in: ids } },
  });
};

const findByStudentIdsAndDate = async (studentIds: string[], date: Date) => {
  return prisma.attendance.findMany({
    where: {
      studentId: { in: studentIds },
      date: {
        gte: new Date(date.setHours(0, 0, 0, 0)),
        lt: new Date(date.setHours(23, 59, 59, 999)),
      },
    },
    include: { student: true },
  });
};

const createBulk = async (
  data: Array<{ studentId: string; status: Status; date: Date }>,
) => {
  return prisma.attendance.createMany({
    data,
    skipDuplicates: false,
  });
};
```

**Update handler `create`:**

```typescript
create: async (req: Request, res: Response) => {
  try {
    // Deteksi format: jika ada field 'classId' dan 'absensi', gunakan bulk
    if (req.body.classId && req.body.absensi) {
      const attendance = await createBulkAttendance(req.body);
      return res.status(201).send({
        message: "Absensi berhasil dibuat",
        data: attendance,
      });
    }

    // Fallback ke single record format (backward compatibility)
    const attendance = await createAttendance(req.body);
    return res.status(201).send({
      message: "Absensi berhasil dibuat",
      data: attendance,
    });
  } catch (err) {
    const message = err instanceof Error ? err.message : "Terjadi kesalahan";
    res.status(400).send({ message });
  }
},
```

## Backward Compatibility

- Tetap support single record format untuk endpoint lain
- Method `createAttendance` tetap ada untuk keperluan lain
- Controller auto-detect format berdasarkan field yang ada

## Validasi yang Dilakukan

- Pastikan semua students dalam array ada di database
- Pastikan semua students ada di class yang diminta
- Pastikan tidak ada duplicate attendance untuk tanggal yang sama
- Pastikan status valid (HADIR, SAKIT, IZIN, ALPHA)
- Pastikan array tidak kosong
- Pastikan tanggal dan classId ada
